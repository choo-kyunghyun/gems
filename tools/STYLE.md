# Style

This is what every visual asset shares. The contracts (palette, sizes, alpha, file formats) are in
`PALETTE.md`, `SPRITE.md` and `MESH.md`.

| | |
|---|---|
| Scale | 32 px per cell. The world cell is 32 px, so one art px is one world px. |
| Palette | AAP-64 only. |
| Outline | 1 px, only on what must read apart from the ground: people, creatures and items. Nothing else is outlined. |
