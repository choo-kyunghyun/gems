# WORLD

## 개요

- 무대: 태양계, 불의 행성(화성, Fire Planet)
- 시대: 게임 현재 기준 24세기 말~25세기 (연표 참조)
- 문명 단계: 인류는 이미 타 항성계로 확산한 성간 문명이며, 문명의 중심이 떠난 태양계는 변경이 되었다
- 테라포밍 방식: 소행성대의 소행성을 화성으로 유도 충돌시키는 휘발성 물질 배달 + 충돌열 가열

## 톤

- 아주 잔혹한 생존물 — 플레이어의 고난과 고뇌가 중심 정서
- 플레이어를 조이는 삼중 압박: 환경의 가혹함, 끝없는 레이더의 방해, 진실을 은폐하는 연합 사령부
- 사령부는 파견자인 사령관에게도 진실을 숨긴다 — 아군이어야 할 본부가 세 번째 압박이 되는 구조
- 기술 미학은 낡은 미래(used future) — 전성기의 고성능 유산이 긁히고 덧대지고 수리된 채 쓰인다
- 새것은 없다: 연합 장비는 규격품의 관료적 낡음, 레이더 장비는 약탈·개조품의 누더기, 식민지 시설은 현지 조달의 임시변통
- 아트·텍스트·사운드의 판단 기준은 이 톤과 미학이다

## 명칭

- 불의 별(Fire Star): 화성의 작중 통칭. 한자 화성(火星)의 직역이며, 공식 명칭 "화성(Mars)"은 구시대 기록에만 남아 있다
- 인류 연합(United Humanity, UH): 연합 기구의 정식 명칭. UN의 후속 기구라는 설정이나 UN은 작중에서 직접 언급되지 않는다
- 레이더(Raider): 범죄 조직의 통칭
- 식민지: 단일 정착지가 아닌 중앙 식민지 + 전초기지 구조. 각 거점의 코드명은 무작위 생성된 단어 조합

## 테라포밍

### 방식과 근거

화성 현지의 CO₂만으로는 테라포밍이 불가능하다는 것이 정설이 된 후, 연합은 외부에서 휘발성 물질을 배달하는 소행성 유도 폭격을 채택했다. 새로운 물리학이 필요 없는 하드 SF 범위의 시나리오다.

- 소행성대 전체 질량은 약 3×10²¹ kg으로 화성의 0.5%에 불과 — 중력 증강은 불가능하며 목적은 오직 휘발성 물질(물, CO₂, 암모니아)과 충돌열
- 1기압 대기에는 기체 약 4×10¹⁸ kg이 필요 — 소행성의 휘발성 비율을 감안하면 소행성대의 0.1~1%를 원료로 소모
- 이송 수단은 핵융합 터그와 매스 드라이버, 이송 하나에 수 년~수십 년 — 자율 군집으로 병렬화하여 캠페인 전체를 약 한 세기로 압축
- 충돌 하나하나가 수만 메가톤급이므로 캠페인 기간 동안 행성 전역은 무인 — 폭격 → 철수 → 재입주라는 시놉시스 구조의 근거

### 실패의 구조

이 방식의 과학적 약점들이 "불완전한 테라포밍"을 설명한다.

- 질소 결핍: 소행성대는 질소가 빈약하며 완충 기체는 외행성계(타이탄권)에서 가져와야 했으나, 연합은 비용을 이유로 소행성대 물질로만 진행 — 얇고 산소 분압이 아슬아슬한 대기의 원인
- 충돌 침식: 과대 충돌은 오히려 대기를 우주로 날려버림 — "계산보다 대기가 덜 쌓인" 원인
- 자기장 부재로 인한 대기 유실은 수백만 년 단위로, 게임 시간축에서는 무시
- 철수 후 대기가 예측을 벗어나 저절로 안정된 것은 공식적으로 원인 불명 — 실체는 "진실" 절 참조

## 연표

| 시기 | 사건 |
|---|---|
| 2080~2140년대 | 행성간 산업화 — 소행성대 채굴, 융합 터그 상용화 |
| 2140~2260년대 | 테라포밍 캠페인(약 120년) — 소행성 유도 폭격, 행성 전역 무인화 |
| 2200년대 | 동면·장기 항행 실용화, 탐사선들이 자연 거주 가능 행성을 잇달아 확인 |
| 2260년대 | 원인 불명의 이상 → 프로젝트 중단, 연합 철수 — "고쳐 쓰는 시대"의 종언 |
| 2260~2380년대 | 이주 세기 — 자본·인구의 신항성계 유출과 태양계 변경화, 그 여파인 국지 분쟁·군벌화, 말기에 무법자 유입; 분쟁 중 조작 병원체의 실전 사용 참사가 성간 협약의 생명 공학 병기화 금지 조항을 낳음; 방치된 화성의 대기는 예측을 벗어나 안정화 |
| 2390년대~ | 게임 현재 — 연합 전초기지 파견 |

## 시대상

### 중심 이동

- 사유는 전쟁이나 태양 이변 같은 밀어내는 힘이 아니라 끌어당기는 힘 — 동면·장기 항행의 실용화와 자연 거주 가능 행성의 확인으로, 죽은 행성을 한 세기 걸려 고치는 것보다 이미 푸른 행성으로 떠나는 쪽이 싸졌다
- 화성 테라포밍 실패는 인류 최대의 투자가 무너진 사건으로, "고쳐 쓰는 시대"에 대한 신뢰를 꺾은 이주의 방아쇠
- 태양계 내 국지 분쟁과 군벌화는 이주의 원인이 아니라 여파 — 쪼그라드는 파이를 놓고 벌어진 다툼이며, 치안 공백과 무법자 유입의 배경

### 연합과 사령관

- 성간 질서는 다극 — 이주 세기에 독립한 신흥 항성국가들이 인류 연합과 경쟁하며, 구질서의 기구인 연합은 상대적 쇠퇴기에 있다
- 인류 연합은 UN의 후계자이자 성간 협약의 관리자 — 협약은 생명 공학의 병기화(인체 개조)를 금지하며, 연합은 그 집행 주체다. 금지 조항의 직접 계기는 이주 세기의 병원체 참사
- 인류의 중심은 타 항성계로 이동했고 태양계는 상징성만 남은 변경
- 연합 기구는 본성계에서 태양계를 원거리 통치하며, 범죄 근원 제거라는 명분으로 개입 — 실제 목적은 "진실" 절 참조
- 성간 항해는 수십 년 단위이며 동면이 표준 — 사령관의 동면 항해(튜토리얼)의 근거
- 사령관은 타 항성계에서 파견된 외부인 — 식민지 주민·무법자와의 시점 차이

## 기술 수준

분야마다 도달점이 다르다. 캠페인 시대(전성기)의 유산은 높은 수준이나, 이주 세기 이후 태양계에 남은 것은 노후했거나 열화된 사본이다.

| 분야 | 수준 |
|---|---|
| 추진·항행 | 융합 추진 성숙, FTL 부재 — 성간 항해는 아광속 수십 년 |
| 동면·생명유지 | 성숙 — 성간 이동의 표준 |
| 통신 | 광속 한계 — 본성계와의 왕복 교신에 수 년, 원거리 통치의 공백과 사령관 재량권의 근거 |
| 자동화·AI | 캠페인 시대의 자율 군집이 정점, 현재는 유지보수 위주로 퇴보 |
| 행성 공학 | 실전(失傳)된 기술 — 캠페인 실패와 이주 세기를 거치며 사장, 진원의 가치를 키우는 배경 |
| 무기 | 실탄 화기 중심, 에너지 병기는 연합 정예 장비로 희소 |
| 의료 | 동면 의학은 성숙, 변경에서는 물자 부족이 병목 |
| 에너지·제조 | 융합로와 현지 조달 제조 — 식민지 건설 게임플레이의 근거 |
| 생명 공학 | 성간 협약이 병기화(인체 개조)를 금지 — 공개 영역은 억제되어 있으나, 비밀 프로그램이 실질적 정점 |

## 기업

인공물 에셋은 단일 스타일이 아니라 가상 기업 체계로 제작한다 — 에셋의 최종 모습 = 기업 기본 테마(제조사) + 세력 오버레이(사용자). 상세는 CORPS.md 참조.

- 프로메테우스 행성공학: 캠페인 시대의 주계약자, 소멸 — 유적과 진원 플랫폼의 출처
- 연합 병기창: 협약 집행의 무력 — 화기와 방어 시설
- 솜누스 성간: 동면과 성간 항해의 인프라 — 튜토리얼 우주선
- 홈스테드 개척산업: 변경의 생활 — 식민지 구조물
- 파나케이아 생명과학: 표면상 의료, 이면은 회색 시장 — 약물과 임플란트, 진원 기술 혈통이라는 소문
- 무명 제작: 레이더 개조품과 현지 임시변통

## 진실

후반 공개용 스포일러. 초반 에셋·레벨에 복선을 심는 기준이 된다.

- 진원의 정체: 캠페인 말기에 비밀 투입된 불법 합성 생물학 플랫폼 — 토양과 화합물에 묶인 질소를 대기로 방출하고 산소·온실 기체의 비율을 조절하는 설계 생태계
- 과학 전제: 질소는 원소라 다른 기체로부터 합성할 수 없다. 캠페인이 배달한 암모니아·질소 화합물과 토양 질산염에 이미 묶여 있는 질소를 탈질 작용으로 방출하는 것 — 교과서 미생물학의 범위
- "원인 불명의 이상"(2260년대)의 실체: 생물학 요소가 통제를 벗어난 사건 — 연합은 은폐하고 철수했다
- 대기의 "안정"은 피드백 조절의 증거 — 무기물 과정은 평형을 유지하지 못하므로, 이 논리가 작중에서 진실에 접근하는 단서
- 행성 개조와 인체 개조는 같은 기술의 두 응용 — 연합은 협약의 수호자이면서, 신흥 항성국가들을 추월하기 위해 격리된 불의 별에서 병기화 연구를 비밀 재개하려 한다
- 귀환의 실제 목적: 플랫폼의 회수와 연구 재개 — "치안 회복"은 명분

## 생명 공학

세계관의 중심 기술을 플레이어가 직접 다루는 축. 여기에는 시스템의 근거가 되는 설정만 담고, 상세 목록과 밸런스는 별도 설계 문서의 몫이다.

### 합법성 3계층

| 계층 | 내용 | 입수처 |
|---|---|---|
| 의료 보정 (합법) | 저압 적응, 재생 촉진, 동면 후유증 관리 | 식민지 의무실 |
| 군용 강화 (회색지대) | 반응속도·근골격 강화, 감각 증폭 — 협약의 빈틈 | 연합 보급, 사령관의 기본 사양 |
| 병기화 개조 (불법) | 전투 특화 체세포 개조 — 협약 위반 | 레이더 암시장, 캠페인 유적, 후반 플랫폼 기술 |

- 플레이어의 강화 진행은 연합이 몰래 오르는 것과 같은 사다리 — 진실 공개 시점에 플레이어의 선택 이력이 서사의 거울이 된다
- 변경이라 가능하다 — 본성계에서 수 광년, 협약의 감시자가 없다

### 약물과 개조

- 약물(스팀): 소모성 버프 + 비용(사용 후 쇠약, 내성, 의존성) — 산소 효율 증진제, 전투 자극제, 지혈·재생제, 방사선 보호제. 비용은 바이탈 시스템에 표시되며 튜토리얼의 바이탈 체크가 이 시스템의 도입부
- 개조: 슬롯 기반 영구 강화 + 되돌리기 어려운 부작용 — 소모품은 "빌리는 힘", 개조는 "파는 몸"

### 같은 기술, 세 개의 얼굴

- 레이더 개조체: 유적 기술로 한 조잡한 자가 개조 — 비대칭, 불안정, 겉으로 드러남
- 연합 개조 정예: 정밀하고 흔적 없는 개조 — 후반에야 정체 노출
- 변이 생물: 설계 생태계의 이탈이 만든 비의도적 결과
- 세력별 실루엣 구분이 설정 차원에서 해결됨 — 스프라이트 시각 언어의 기준

### 생화학 무기

- 과거: 이주 세기의 국지 분쟁에서 조작 병원체가 실전 사용된 참사 — 협약의 병기화 금지 조항의 직접 계기
- 환경성 감염: 이탈 생태계에서 파생된 기회감염성 변종 — 의도 없는 자연재해형 위협, 식민지의 질병·검역 이벤트의 근거
- 의도적 병기화: 연합 비밀 프로그램의 목표이자 후반 서사의 위협 — 레이더의 조잡한 "더러운 무기"가 중간 단계

## 결말

고난 끝에 진실을 마주한 플레이어가 둘 중 하나를 선택한다.

- 수용: 연합의 진실을 이해하고 받아들인다 — 최종 적들과 같은 수준의 인체 개조를 스스로 수용하며, 합법성 사다리의 꼭대기에 오른다
- 거부: 위법성과 위선에 치를 떨고 연구 시설을 폭파한다
- 플레이 중의 약물·개조 선택 이력이 결말 선택의 정서적 무게를 만든다 — 생명 공학 절의 "서사의 거울"이 수렴하는 지점

## 게임플레이 근거

세계관이 직접 정당화하는 시스템·에셋 요소.

- 얇은 대기: 실외 활동에 여압·필터 장비 필요, 고도에 따른 위험 — 생존 게임플레이의 근거
- 충돌 크레이터: 분지·크레이터 호수 등 레벨 지형의 기본 어휘
- 캠페인 유적: 버려진 융합 터그, 매스 드라이버, 무인 관제 시설 — 복셀 프롭과 탐사 지점
- 대기 안정화의 진원: 후반 서사와 특수 지역·프롭의 원천
- 중앙 식민지 + 전초기지 구조: World(레벨 묶음)–Level 아키텍처와 대응, 거점 코드명은 절차 생성
- 합성 생물학: 변이 생물(설계 생태계의 이탈·변이체)과 후반 적 유닛(연합 개조 정예)의 원천
- 약물·개조: 소모성 스팀과 영구 개조 슬롯 — 플레이어 강화 진행의 축, 의존성·부작용은 바이탈 UI와 연동
- 질병·검역: 환경성 감염 변종 — 격리·방역·의무실 가동 등 식민지 관리 이벤트의 근거
- 생명 공학 에셋 배당: 의무실·검역소·배양 시설(복셀), 약물·임플란트(아이템 아이콘), 개조체 스프라이트 변형 3종

## 미결 사항

- 코드명 생성용 단어 풀 설계, 중앙 식민지의 고정 서사용 코드명 필요 여부
- 바이옴 구성과 환경 위험 요소, 변이 생물의 구체적 구성 — 변이의 원인은 설계 생태계의 이탈로 확정
- 레이더의 조직 구조(단일 신디케이트 vs 복수 갱단)와 중립 세력의 존재
- 신흥 항성국가들의 구체상 — 작중 직접 등장 여부와 명칭 필요 여부
- 약물·개조의 상세 목록과 밸런스 — 별도 설계 문서에서
- 플레이어의 불법 개조에 대한 서사 반응(식민지 주민·연합 감사) 설계 여부
- 폭파 대상 시설과 진원의 관계 — 파괴가 대기 조절에 미치는 영향과 거부 엔딩의 후일담 처리
