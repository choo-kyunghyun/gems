# G.E.M.S. Architecture — Renderer

Area reference split out of the always-loaded core ([ARCHITECTURE.md](../ARCHITECTURE.md)). Loaded on demand: **Read this file before designing or modifying anything in this area.** Runtime quirks live in [GMRT.md](../GMRT.md).

## Renderer

`Renderer` is an ordered list of `RenderPass` objects (`{ draw(world), destroy() }`); `insert(pass, index?)` / `remove(pass)` manage the list. Each scene owns its renderer and calls `this.renderer.draw(this.world)` in `draw()`.

Built-in passes:

- **`RenderEntity`** — draws `Visual` + `Position` entities via `draw_sprite_ext`, interpolating `PrevPosition → Position` by `World.sim.alpha` when present. An invalid `Visual.sprite` — or an SVG one, which reports 0 frames on GMRT — draws as the **`spr_missing`** placeholder (subimg re-wrapped to its frame range); `RenderBillboard` shares the fallback. Per-entity scalar data (name, facing, animator state) is inspected by clicking the entity in the Debug overlay (`DebugInspector`), not by world-space label passes.
- **`RenderBillboard`** (Core) — the **STANDING pass** of the art projection contract: on pitched 2.5D maps it replaces `RenderEntity`, drawing each sprite **upright** (constant −90 tilt off the ground — deliberately _not_ camera-facing; a perpendicular billboard reclines ~cos(pitch) and buries into wall meshes at contact) as **depth-writing** geometry (z-write on around its loop only), so bodies sort per-pixel against walls/furniture. Sprites submit through **`sh_meshlit`** in textured + cutout mode: the `u_alphaRef` texel discard keeps transparent pixels from writing depth (hard-alpha sprites required), and the sprite sun response runs per-pixel at a **fixed bent normal** riding `u_normal` ((0, 0.5, −0.866), 30° south of straight-up) — authored colors at noon, dimming/warming toward dawn/dusk, torch-side brightening at night. With `opt.lights` = the host `RenderMesh` pass (wired by `RpgMap` on pitched maps) it shares that pass's sun + view-culled point gather, so a sprite and the mesh beside it can't diverge; unset (flat maps, kit default) the pass sets neutral uniforms — full-bright albedo with the cutout only. Draws the `Appearance` paper-doll stack per entity, each layer Y-biased for deterministic depth (rpg.md → _Paper-doll appearance_); composes **under** `RenderLighting`'s multiply exactly like the meshes — the light map owns absolute darkness.
- **`RenderMesh`** (Core) — the **VOLUME pass**: draws every **`Mesh`** + `Position` entity (the 3D counterpart of `Visual`) as depth-writing geometry. Two paths. **Model**: `Mesh.model` submits a baked vox-kit vertex buffer (`meshes/<name>.vbuf`, loaded → frozen → cached) — visual-only `scale`/`xscale`/`yscale`/`zscale` (negative xscale mirrors) plus rotation: `yaw` turns about the footprint center (vbufs bake the top + all FOUR side faces, so any facing renders solid; the shader rotates the packed normals by `mat3(world)`, so lighting follows), `pitch`/`roll` tilt about world x/y (no bottom faces — a >90° tip shows a hollow underside); the BBox stays authored and axis-aligned. Lit by `sh_meshlit`: the buffer carries unshaded albedo + a packed per-face normal (GMRT.md → Capabilities), and the shader computes N·L from an **injected directional sun** (`opt.sun`, wired to `WorldClock.sunDir()` by `RpgMap`; default a fixed neutral sun, so a kit consumer gets shading with zero wiring) plus the nearest **`Light`** entities as point lights (up to 8, nearest-to-view-center when over budget via the assigned `pass.camera`) — a torch lights the faces that FACE it while the light map supplies the visible glow pool; no-shader fallback = flat albedo. **Analytic box**: a plan-view TOP quad at `-height` + a vertical FRONT at the south edge (sprite-or-color faces), drawn outside the lit shader (its texcoords are real UVs). **A mesh entity carries `Mesh` INSTEAD of `Visual`** — the billboard/shadow passes query `Visual` and skip it for free (`CombatAI`'s `Visual` reads are guarded, so a mesh turret is a legal combatant). Model sources are `.vox` templates in `tools/vox-kit/`, baked greedy-meshed by `vox2vbuf.py` (the 24 B/vertex lockstep contract, GMRT.md → Capabilities); its `meshes.json` manifest also drives the prop colliders (`RpgSpawn.footprint`: `max(8, content − 2)` per axis). Inserted by `RpgMap.build` on pitched maps, between the shadow and entity passes.
- **`RenderWalls`** (Core) — the **WALLS pass**: draws a solid `TileLayer` as lit boxes — per wall cell a plan-view TOP quad at `-height` plus a vertical SOUTH face only where the south neighbor is empty (the two orientations the fixed-yaw pitched camera can see; hidden-face removal happens at **build time**, so nothing emitted can backface and GPU cull modes are moot). Vertices are the vox-kit 24 B format in one of two `sh_meshlit` modes: **textured** (`opt.sprite` + `opt.frame`) puts real frame UVs in the texcoord and the material tint in the COLOUR channel (`texture × tint × light` — one grayscale-ish pattern serves every material color by tint), with the face normal riding the **`u_normal` uniform**, constant per orientation — tops and souths live in separate VBOs submitted under `u_useTex = 1` with the normal swapped between (uniforms fsh-declared only — the one-stage rule, _Shader rules_ below); **flat tint** (no sprite, and the sprite-missing fallback) packs the normal in the texcoord like the vox models. `opt.lights` is the host `RenderMesh` pass, whose `_setupLights` supplies the frame's sun + point lights (and pins `u_useTex = 0` for the vox models). VBO-cached: `markDirty()` after tile edits (`BuildMode._markTileDirty` reaches it via `scene._tilePasses.wall`). **`opt.materials`** (`[{ id, sprite, frame, color }]`) buckets cells by their `TileType` id so ONE solid layer renders per-cell wall materials (each bucket its own VBO pair; an unmatched cell falls to the default bucket) — the RPG's material set lives in `RpgLevel.LAYERS`. The `layer` only needs `get(gx, gy)` truthiness, so any occupancy view satisfies it — `RpgMap._buildRenderer` inserts the pass **twice** on pitched maps: the resident wall layer (interiors + player builds), and on the chunked overworld a second instance over **`ChunkManager.wallLayer()`**, the whole-store occupancy view (immutable after `pregenerate()`, so it rasterizes once on first draw with no streaming coupling; `RenderChunks`' flat wall rects are disabled via its `walls` opt).
- **`RenderTileMap`** — hardware-accelerated tiles via `VertexBuffer`; `.markDirty()` after tile changes rebuilds the VBO. `opt.autotile`: `0` = raw frame id, `16` = blob4, `47` = blob8, `"dual"` = dual-grid corner sampling, `"corner"` = quarter/sub-tile. Neighbor bits: `N=1, E=2, S=4, W=8` (blob8 adds `NE=16, SE=32, SW=64, NW=128`), so a blob4 tileset's frame index equals its cardinal-neighbor mask.
  - **`"dual"` (dual-grid)** — the blob modes draw one centered tile per _filled cell_ and cannot show two materials meeting. Dual-grid renders a half-cell-**offset** grid where each display tile samples the 4 cells touching a grid _corner_ (corner bits `TL=1, TR=2, BR=4, BL=8` → 16-frame index = mask). Empty corners stay transparent, so **stacking several `"dual"` passes — one `TileLayer` per terrain, lowest priority first** — gives A-over-B terrain transitions with only a 16-frame corner tileset per terrain; the priority stack is just ordered `Renderer` passes. `softEdge` is ignored in dual mode. A full cell (mask 15) picks a **weighted full-tile variant** from the sheet's `SpriteMeta` def (`variants["15"]` = `[[frame, weight], …]` over frames 15+) via a deterministic MINSTD position hash — stable across chunk reloads; an undeclared sheet falls back to uniform weights past frame 15. The reference composition is `TerrainStream`'s per-material stack on the RPG overworld; `RenderTileMap`'s own dual path draws `frame = mask` with no variants (add the same pick when a variant-bearing sheet gets a `RenderTileMap` consumer).
  - **`"corner"` (quarter / sub-tile)** — keys per _cell_ but draws **4 half-cell quadrants**, each quadrant's piece picked independently by the 3 neighbors touching that corner. The 13-piece set (`0` fill · `1-4` outer corners · `5-8` edges · `9-12` inner corners) reproduces the full blob8 look and covers all 256 masks — the per-corner selectors read bits inline off one neighbor int (no cached primitive-bool locals — the `&&`-clobber quirk, GMRT.md §1). Material repeats every half-cell (pieces are position-shared), so borders read rounder than `"dual"`. `softEdge` is per-cell-mode only (ignored for both corner-keyed modes). `tools/pixel-art-kit/common/tileset.py` synthesizes both the 16-frame `"dual"` and 13-piece `"corner"` sets from one material texture.
- **`RenderDebugEntity`** — `BBox` outlines for `Position` + `BBox` entities, interpolated like `RenderEntity`.
- **`RenderDebugPath`** — active `PathResponse` paths + pending `PathRequest` goals.
- **`RenderZone`** — world-space overlay for one **zone channel** (levels.md → Zones): fills each zone's cells and outlines region borders (only edges where the neighbor differs). Color is `zone.data.color` when set, else a stable hue from the zone id. Reads `level.zoneMap(key)` live each frame — a no-op until the channel exists, so it's safe to insert before zones are painted. **`RenderZoneLabel`** draws the zone-name labels at each centroid; split out so labels toggle independently — insert it _after_ the zone pass.
- **`RenderGrid`** — cell boundary lines for a Level's grid; split out of `RenderDebugTileMap` so the grid toggles independently.
- **`RenderChunks`** — world-space pass for a `ChunkManager`'s streamed terrain (rpg.md → _Chunk streaming_). Per active chunk: an opaque ground fill (a subtle checker by chunk parity so seams + streaming read at a glance; unloaded area stays the dark scene background — a visible edge of the loaded world), the chunk's flat wall rects (`opt.walls: false` disables them where `RenderWalls` draws the streamed walls instead), and each LOAD-ring entity **snapshot** as a dimmed box + name. SIM-ring entities are live and drawn by the normal entity passes, so insert this **before** them. The active set is bounded by `loadRadius`, so no per-chunk view cull.
- **`RenderCloudShadow`** (Demo) — screen-space cloud shadows: drifting cumulus clusters (hashed per cloud-grid cell, MINSTD) **multiplied** over the scene (`gpu_set_blendmode_ext(bm_dest_colour, bm_zero)`). Coverage is the condition's `cloud` fraction (cross-faded by `Weather.blend()`) scaled by daylight (`WorldClock.tint` alpha — gone by nightfall, so the night tint never double-darkens); drift scrolls on `Weather.time()`. Inserted just **before `RenderWeather`**, outdoor maps only (`meta.indoor` skips both).
- **`RenderWeather`** (Demo) — world-space weather driven by `Weather`: a condition tint plus rain streaks / snow flakes, **cross-faded** by `Weather.blend()` (outgoing + incoming both drawn during a change). Particles are screen-space over the view rect and scroll on **`Weather.time()`** — the cumulative sim-second clock, never a per-frame delta (so the fall freezes on pause and dilates with `Time.scale`). Inserted **just before `RenderLighting`** so the night/light tint also darkens the rain. Reads the view rect from the held `Camera`'s **own fields** (`camera_get_view_*` returns 0 for the matrix-driven Camera — utilities.md → _Camera_); the scene assigns `pass.camera`.
- **`RenderLighting`** (`Gameplay/Lighting`) — the world-space 2D **light-map** pass: lighting + day/night in one. Per frame it builds an off-screen surface cleared to its **injected `ambient` provider** (`() => { color, alpha }`; the demo wires `WorldClock.tint`) mapped to a multiply model (white in daylight → night hue, scaled by `opt.darkness`), `bm_add`s a soft radial blob for every **`Light`** + `Position` entity (`Light` = `{ radius, color, intensity?, flicker? }`), then composites over the world **multiplicatively** (`gpu_set_blendmode_ext(bm_dest_colour, bm_zero)`; no `bm_multiply` constant). So **day/night is "lighting with no lights"**, and point lights reveal the night. **Self-balancing**: in full daylight the ambient is white, lights clamp to white, the multiply is a no-op — the pass early-outs (zero surface work). Falloff only — no shadows. A **night vignette** multiplies the light map's corners down (baked into the same surface, so it deepens the scene rather than alpha-washing it), scaled by the cycle — gone in daylight with the early-out; `opt.vignette` is the corner fraction at full night (0 disables). Inserted **last** in the RPG renderer. Reads the view rect from the Camera's own fields; the light surface is volatile (lost on resize/focus) — the pass guards `surface_exists` + recreates on a size change.
- **`RenderDebugTileMap`** — overlay: cost shading (reads `level.costAt` live — no sync step), tile id/name + coordinate labels. An optional `camera` (settable later via `pass.camera`) culls iteration to the view rect — required for a large grid; the rect comes from the Camera's own fields, not `camera_get_view_*`.

**`VertexBuffer`** wraps GameMaker vertex buffers with a fixed `position_3d + texcoord + colour` format — quads at z = 0, so a ground VBO can submit under `sh_meshlit` (which reads a 3-component position); ground passes stay z-write-off painter order.

**Ground lighting**: `RenderTileMap` + `TerrainStream` take a `lights` field (the host `RenderMesh` pass) and submit under `sh_meshlit` textured mode with the straight-up normal, so the ground joins the same sun/point-light model as walls/meshes/billboards; unset (kit default, flat maps, the editor) they submit fixed-function unlit.

**Shader rules** (general GameMaker behaviour, identical on GMS2): guard a custom shader with `shaders_are_supported()` + `shader_is_compiled(...)` before `shader_set`, with a non-shader fallback. A shader on an **untextured** primitive reads `gm_BaseTexture` as black — compute output from uniforms only, don't sample. Declare each uniform in exactly **ONE stage**: the same name declared in both stages makes `shader_get_uniform` return the vertex stage's location while the fragment stage reads a default 0 — the symptom is a "working" shader ignoring its flag, not a compile error; pass vertex→fragment via a varying. **`sh_meshlit` is the ONE world shader** — every world pass submits through it in vox or textured mode, with the texel cutout as a uniform mode (`u_alphaRef`, GMRT.md [#14737](https://github.com/YoYoGames/GameMaker-Bugs/issues/14737)); day/night + the vignette stay the `RenderLighting` light map, not a shader.

**Screen-space overlay matrices — up +1 AND negative ortho height**: a pass that resets view/projection to surface-pixel ortho (`RenderLighting`'s composite, `RenderWeather`) must use `matrix_build_lookat(w/2, h/2, -1, w/2, h/2, 0, 0, 1, 0)` + `matrix_build_projection_ortho(w, -h, 0, 2)` — the **negative height**. The overlay path has an inherent Y-flip vs the world camera; negating the UP vector instead is a 180° ROLL — it X-MIRRORS the content about screen center, invisible for symmetric content (ambient fill, vignette, a centered blob) but wrong for anything off-center.
